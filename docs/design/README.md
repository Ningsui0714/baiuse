## 文件与设计系统

- `client-concept.png`：内置 Image Gen 生成的主屏设计参考，1536 × 1024。
- `client-desktop.png`：最终 Claude Code CLI 接入主屏，1536 × 1024 浏览器视口。
- `desktop-in-app-guide.png`：最终 Claude Desktop 应用内引导，1536px 宽，完整页面截图。

保持既有静态应用架构，没有为换皮引入框架。基础样式从 HTML 拆到 `ui/base.css`，统一视觉 token 在 `ui/theme.css`。接入逻辑在 `ui/clients.js`；配置与协议在 `src/clients/`。

设计 token：主背景 `#f3f8ff`、白色表面、侧栏 `#e7f2ff`、主色 `#377df4`、文字 `#152745`、边框 `#dfe8f3`。字体 Avenir Next / PingFang SC，标题 34px、面板标题 22px、控件 13px、代码 12px；小屏采用单列。主视觉采用可缩放 SVG 路由线，不把截图当作界面。

组件：侧栏、轻量 breadcrumb、接入横幅、五个客户端页签、表单/代码双栏、状态标签、页面内确认弹窗、表格、原有账号与供应商弹窗。尊重 reduced-motion，客户端页签支持方向键与 Home/End。

## Image Gen 提示简报

使用内置 imagegen（非 CLI/API）。主屏需求：中文 Codex Relay 本地网关，完整 1536 × 1024 应用截图；浅蓝、通透、克制、可实现的开发者工作空间。左栏含总览/账号管理/模型目录/自备 Key/客户端接入/设置；接入主屏含标题、轻量路由横幅、Codex CLI/Claude Code/Claude Desktop/Gemini CLI/OpenCode 五个选择器、模型下拉、地址、配置路径、一键接入/还原、掩码代码预览和复制操作；不造使用量、不加无关图表/照片/营销徽章；真实控件必须代码实现。生成结果用于布局参考，不携带任何真实凭据。

## 浏览器验收

1. 优先用 IAB 加载真实本地应用（隔离 HOME/数据目录，48761 端口）。Claude Code 一键接入、成功状态、掩码配置均可见。
2. 原生 `confirm()` 使 IAB 的 CDP 交互超时，改为页面内 `<dialog>`，并用 Playwright Chromium 补验。
3. 修复后重新在 IAB 验证「一键接入 → 还原配置 → 确认还原 → 待接入」成功。已重置 IAB 视口。
4. Playwright 在 1536 × 1024 和 390 × 844 检查布局；主屏及桌面引导均没有文档级横向溢出。六个导航页桌面端均能打开且无横向溢出。
5. Playwright 验证 Codex、Claude Code、Gemini CLI、OpenCode 四者的接入及还原闭环；Claude Desktop 只准备网关参数，状态为「参数已准备 · 待应用内配置」，不存在该状态下的「一键接入」按钮。
6. `view_image` 已检查设计参考、最终实现主屏、桌面引导和移动端截图。

截图与交互均为隔离测试配置，不修改用户现有 Claude/Codex/Gemini/OpenCode 配置。并未在用户的 Claude Desktop 内实际应用 Gateway。

## 视觉核验与偏差记录

| 对比点 | 参考 | 实现与修复 |
| --- | --- | --- |
| 整体布局 | 浅蓝侧栏 + 浅蓝工作区 + 白色表单 | 保留同一骨架；256px 侧栏、双栏表单，小屏改为顶栏/单列 |
| 字体层级 | 大标题、明确面板标题、可读代码 | 初稿偏小，已将标题调整至 34px、控件至 13px、代码至 12px |
| 配色 | 冰蓝底、白表面、蓝色选中态 | 全局显式 light token，不跟随系统切暗色；未把白色改成暖白 |
| 组件/间距 | 五个工具横排，表单与代码并列 | 保留 5 个入口、统一边框/圆角/间距；不制造嵌套卡片墙 |
| 图标与媒体 | 工具识别图标与简单路由线 | 代码原生 SVG/文字标记；没有以截图替代交互或添加图片色罩 |
| 文案 | 客户端接入 + 原生字段 | 首屏主标题、导航、入口名称与语义保留；真实模型/状态替代示例假值 |
| 桌面模式 | 参考图未展开 | 按用户追加要求加入应用内三步向导；复制参数、准备映射不等于接入成功 |
| 响应式 | 主屏桌面为主 | 390px 下 5 个入口仍可操作、代码块内部滚动，不挤出页面 |

首屏文案差异：刻意去掉概念图中的 macOS 装饰交通灯、虚构 `mcp.enabled` 配置、静态「已就绪」和过时示例模型；新增真实备份/错误反馈。桌面页横幅改为「桌面接入，在应用内完成。」，避免误导为文件式接入。与概念图的字体字号、部分说明文案及状态属于上述有意调整，不声称逐像素复制。已经忠实核验整体视觉系统，没有遗留裁切、溢出、假按钮或原生确认框阻塞问题。
