# 账号实测、每日领取与有道龙虾移除

日期：2026-10-26；真实账号测试使用本机已保存的授权。本文不包含账号 ID、昵称、手机号、凭据或完整客户端配置。

## 方法与边界

- 最初识别到 8 个已登录渠道，逐个发送 `Reply with only BAIUSE_OK.`，检查实际正文，不以“已登录”或“存在模型目录”代替推理验证。
- 使用渠道已注册的适配器，固定一个账号凭据，移除内部账号池和 `nextAccount`；不走网关自动换路。Raccoon 和 MiniMax 不再误用旧 `account.test` 的 CodeArts 兜底分支。
- 优先轻量 / 标注免费模型，Qoder 的 `qfmodel` 等不透明 ID 根据显示名选择。额度不足的 Auto 模型失败，不等于该账号的免费 Flash 模型也失败。
- 单次诊断的输出预算为 1024、超时为 90 秒；只作用于测试，不修改正常对话的输入输出预算或客户端设置。测试会消耗少量上游额度。
- 空响应判为失败，错误与凭据脱敏后保存；请求时不会自动完成验证码。验证码相关领取保留官方入口。

## 自动签到与活动时间

自动开关沿用渠道包已有日计划，不另建外部任务：每日首次启动后延迟执行，应用退出后不运行；同日重复启动不会重复计作新领取。部分活动在 10:00 更新领取窗口，新窗口开放后可手动补领。

- 华为云官方 [每日签到得积分](https://support.huaweicloud.com/offers-codeartsagent/codeartsagent_offers_0004.html)：按积分计费与活动资格适用。
- Qoder CN 官方 [每日领取 100 Credits](https://docs.qoder.cn/events/100credits)：北京时间 10:00 开新窗口，奖励按各次领取时间分别计算有效期。
- Qoder 官方 [每日领取活动](https://docs.qoder.com/events/100credits)：以账号实际下发活动与页面规则为准。
