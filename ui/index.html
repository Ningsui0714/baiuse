只改 config.toml，auth.json 一个字节都不会动 —— 官方登录态、App 的远程操作与官方插件都保留。

供应商

每张卡是一份直连配置：切换后 Codex 直接连那一家，不经过本机网关。 想让流量走网关（自动故障转移），就切到「本机网关」那张卡。

Codex 账号
